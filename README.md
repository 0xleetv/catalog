# 0xleetv Studio Asset Catalog

The full tool catalog for 0xleetv Studio (UI/UX and interaction design). Every repo here is a fork or extracted reference under this account, so any coding agent can pull them by name. Links go to the copies in this catalog.

## Motion and video

1. [HyperFrames](https://github.com/0xleetv/hyperframes): HeyGen's open source HTML to video framework (Apache 2.0). Write the animation as a web page, render frame by frame to MP4 in headless Chrome with FFmpeg. About 450 ready blocks for kinetic type, transitions, captions, charts and 3D. Ships as agent skills in `.agents/skills` and `.claude/skills`.
2. [Remotion](https://github.com/0xleetv/remotion): programmatic video in React. Render React components to real video files.
3. [MotionSites Web Builder skill](https://github.com/0xleetv/claude-skill): agent skill for award level cinematic landing pages. 40 example prompts, a media shelf of cinematic hero videos and transparent 3D cutouts, 55+ technique recipes with working code. Skill code is MIT; example prompts and media remain (c) MotionSites. The packaged skill zip sits at the repo root (`motionsites-web-builder.zip`).

## UI components and interaction

4. [React Bits](https://github.com/0xleetv/react-bits): animated, interactive React components.
5. [ReactDrops](https://github.com/0xleetv/reactdrops): WebGL 2 shaders and liquid glass effects.
6. [Uiverse Galaxy](https://github.com/0xleetv/galaxy): community library of 7,000+ CSS and Tailwind components.
7. [ForgeUI](https://github.com/0xleetv/forgeui): copy-in component system for marketing sites, 74 React components on Tailwind v4.
8. [Flowbite](https://github.com/0xleetv/flowbite): open source UI component library and frontend framework.
9. [Perfect Freehand](https://github.com/0xleetv/perfect-freehand): pressure sensitive freehand drawing.
10. [Hover Effect](https://github.com/0xleetv/hover-effect): image distortion and hover animations.
11. [Atropos](https://github.com/0xleetv/atropos): touch friendly 3D parallax hover effects.

## 3D and WebGL

12. [City Tour](https://github.com/0xleetv/city-tour): procedurally generated city built with WebGL and three.js.
13. [Google Model Viewer](https://github.com/0xleetv/model-viewer): interactive 3D models on the web and in AR.
14. [Sketchfab Viewer API](https://github.com/0xleetv/viewer-api): embed and drive Sketchfab 3D viewers.

## Maps, typography and print

15. [Terraink](https://github.com/0xleetv/terraink): cartographic poster engine, vector maps with print export.
16. [Coddy Round](https://github.com/0xleetv/coddy-round): Audiowide rounded display typeface.

## Tool directory

17. [NoSignups](https://github.com/0xleetv/NoSignups): directory of 274 open source, in browser tools that need no signup. Categories: development, design and graphics, productivity, media, writing, data, privacy and more.

## Study references

Extracted code kept for mechanics and architecture study, not for redeployment.

18. [CityRT](https://github.com/0xleetv/cityrt): extracted client bundle from a live city builder site: canvas simulation loop, touch gesture controls, district registry.
19. [AutoDraw](https://github.com/0xleetv/autodraw): extracted Google AutoDraw assets for drawing suggestion mechanics.
20. [Coddy Focus](https://github.com/0xleetv/coddy-focus): open source website blocker and focus timer; focus mechanics reference.

## Indexed sites (not forked)

- [Sketchfab](https://sketchfab.com): 3D model library and viewer.
- [PNGimg](https://pngimg.com): 100,000+ transparent PNG cutouts.
- [Uilora](https://www.uilora.com): 700+ animated components for web and mobile, installed through its CLI.
